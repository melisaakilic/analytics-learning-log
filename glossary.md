# Glossary — Week 1

**query** — A request written in SQL to retrieve or manipulate data from a database.

**dataframe** — A table-like data structure in pandas with rows and columns.

**aggregate** — A function that combines many rows into a single value (e.g. SUM, COUNT, AVG).

**commit** — A saved snapshot of changes in a Git repository.

**repository** — A storage space (local or on GitHub) that holds a project's files and history.
